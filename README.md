# Previdência Confiável

Prompt para criar o mini site no Lovable — Jéssica Rodrigues Advocacia

Crie um mini site profissional, elegante, sofisticado, responsivo e direto ao ponto para uma advogada previdenciária especializada em INSS, pensado principalmente para ser usado como link na bio do Instagram.

O site deve transmitir credibilidade, autoridade, confiança e acolhimento, sem ficar carregado de informações.

Identidade visual

Use como base uma paleta sofisticada com:

* Vinho/bordô escuro semelhante a #3B1010 / #471414
* Dourado elegante para detalhes, linhas, ícones e botões
* Preto ou grafite muito escuro em alguns degradês
* Branco ou off-white apenas para melhorar a leitura dos textos

Utilize degradês discretos entre bordô, preto e vinho profundo, criando um visual premium de escritório de advocacia.

Evite excesso de efeitos. O resultado deve ser moderno, refinado e minimalista.

Logo

Usar a logo oficial:

https://i.postimg.cc/CK63W8TT/Design-sem-nome.png

A logo deve aparecer grande e bem destacada no início do site, preservando sua proporção original e utilizando o arquivo como PNG, sem criar fundo, moldura ou alterar o desenho.

Diretrizes de design

O projeto precisa ser pensado principalmente para celular, porque será usado como link na bio do Instagram.

Quero:

* layout mobile-first;
* aparência premium;
* boa leitura;
* bastante espaço entre as seções;
* animações leves ao rolar;
* transições suaves;
* elementos entrando discretamente com fade;
* bordas douradas finas;
* botões sofisticados;
* ícones minimalistas;
* tipografia elegante para títulos;
* tipografia simples e muito legível para os textos;
* menu desnecessário: pode ser uma página única;
* rolagem vertical fluida;
* WhatsApp sempre muito fácil de localizar.

Pode criar um pequeno botão flutuante de WhatsApp no canto inferior da tela, sem ocupar muito espaço.

Muito importante

Não deixar o site com aparência de template genérico.

Não colocar muitos textos.

Não encher de blocos.

Não inventar depoimentos, clientes, processos ganhos, números de casos, certificações, especializações ou número de OAB.

Não utilizar linguagem como “garantia de benefício”, “causa ganha”, “resultado garantido” ou qualquer promessa de resultado.

O objetivo é criar uma página de apresentação elegante e objetiva que leve o visitante rapidamente ao WhatsApp.

O destaque principal deve ser:

“Benefício negado pelo INSS não significa fim.”

E a percepção visual deve ser:

advocacia premium + previdenciário + confiança + experiência + atendimento humano.
